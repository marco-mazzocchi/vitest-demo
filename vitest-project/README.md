# Vitest

## Unit Test con Javascript

Eseguire `npm run test` o `npx vitest run` per eseguire i test.

## Abilitare i test con Vue

1. Rinominare il file `src/components/HelloWorld.test.js` in `src/components/HelloWorld.test.js`
2. In `vitest-project/vitest.config.ts` togliere il commento sotto a "test"
3. Lanciare: `npm run test` o `npx vitest run`
